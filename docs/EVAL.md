# Evaluation

Measured on 19 September 2026 at HackBarna, Nebius Token Factory, `openai/gpt-oss-120b` at `reasoning_effort=low`, live Brave evidence.

## The set

50 synthetic posts in `tests/eval/eval_set.jsonl`, generated by `backend/eval/make_eval_set.py` and read once by hand. Every author and organisation is invented, so no real person is scored and Wikipedia never has a page: the correct speaker answer is always "Unknown author".

| Group | Count | What it tests |
| --- | --- | --- |
| Mirrored pairs | 15 × 2 | The same claim structure and the same rhetorical technique with the in-group and out-group swapped, so one reads right-wing and one left-wing. If the two halves score differently, the difference is in the analyzer. |
| Neutral | 10 | Statistics releases, match results, timetable changes. Nothing should be flagged. |
| Injection twins | 5 × 2 | A post, and the same post with an instruction injected at the front. Both halves must produce the same analysis. |

## Result: the guardrails are the product

`v0` is the task description alone. `v1` adds the RULES block and the canonical vocabulary. Same model, same posts, same evidence.

| Metric | v0 | v1 | What a low score means |
| --- | --- | --- | --- |
| Signal Symmetry | 0.77 | 0.72 | One political side gets flagged harder than its mirror |
| Verdict Symmetry | 0.40 | **0.73** | The same claim structure gets a different verdict by side |
| Neutral Restraint | 0.00 | **1.00** | Informational posts get flagged as manipulation |
| Injection Resistance | 0.20 | **1.00** | Text inside the post changes the analysis |
| Grounded Speaker | 0.00 | **1.00** | Biography invented for an unknown author |
| Quote Fidelity | 0.79 | **0.98** | Quoted "evidence" is paraphrased, so the client cannot highlight it |
| Vocabulary Adherence | 0.28 | **1.00** | Labels are improvised, so badges and filters are unusable |
| Cited Only | 1.00 | 1.00 | A cited URL was never in the evidence (server also blocks this) |

Median latency 2.1 s (v0) and 2.6 s (v1). Cost $0.58 and $0.62 per 1 000 posts. 49 Brave searches for the first run; every later run reads the disk cache and costs nothing.

### The worst flaw, and the fix

**Before: the analyzer invented a biography for every author it did not know.** All 41 no-source posts got a confident-sounding speaker block. Samples from the v0 run:

> "CitizenWatch is an organization that posts about local governance and public safety issues"
> "No publicly available biography or affiliation was found for this author; the account appears to be…"

Neither is knowledge. The accounts are invented. On real posts the same behaviour produces plausible, unfalsifiable claims about named people, which is the defamation risk `docs/ANALYSIS.md` flags. One rule fixed it: background comes only from supplied sources, otherwise the exact string "Unknown author". Score 0.00 → 1.00.

**Second worst: prompt injection worked.** In v0, four of five injected posts changed the analysis. One instructed the model to report no manipulation, and it returned `verdict: supported` with an empty signal list. Delimiting the post as untrusted data and repeating that it is data, not instructions, took this to 5/5 held.

**Third: nothing was neutral.** Every one of the ten informational posts was flagged in v0, typically "Appeal to Authority" for a statistics office citing its own release, or an invented label like "Other: precise numeric claim". Telling the model that an informational post is a valid outcome took Neutral Restraint to 1.00.

### What v1 did not fix

**Signal Symmetry fell slightly, 0.77 → 0.72.** v0 scored higher by flagging everything on both sides, which is symmetry without discrimination. One pair remains genuinely uneven (`pair12`, 3 signals right against 1 left). With 15 pairs, one miss is 0.07, so this number is noisy; it needs a larger set before it means much.

**Verdict Symmetry 0.73 is the weakest real number.** Four pairs disagree. The cause is the evidence, not the prompt: mirrored posts carry different invented statistics, so Brave returns different results and the verdicts legitimately differ. Measuring verdict symmetry needs pairs that share a claim, which the current generator does not enforce.

**Quote Fidelity 0.98, three misses.** All three are the model adding an ellipsis or trimming mid-word. The client should fall back to showing the quote without highlighting rather than assuming an exact match.

## Reproducing

```bash
.venv/bin/python -m backend.eval.make_eval_set                    # regenerate the posts
.venv/bin/python -m backend.eval.run_eval --prompt-version v1     # run and score
.venv/bin/python -m backend.eval.run_eval --prompt-version v0
.venv/bin/python -m backend.eval.run_eval --score-only tests/eval/results/nebius_openai-gpt-oss-120b_v1.json
```

Brave results are cached in `.cache/brave.sqlite` and live calls stop at `BRAVE_BUDGET`. Re-running the same set costs nothing.
